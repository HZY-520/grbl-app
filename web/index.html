      使用说明
      
    

    

      
    
        
  1. 选择输入：文字标签页直接输入文本；图片标签页上传位图（照片 / 线稿均可）；SVG 标签页上传或粘贴矢量源码。
    2. 
        
  2. 选择生成模式：矢量图形（文字轮廓 / SVG）生成干净的描边或填充路径；位图可选抖动、灰度、半色调或矢量化描边。
    3. 
        
  3. 填写设备参数：先在「设备参数」中填写机器行程 X / Y、原点位置、安全边距与最大进给，参数会自动记忆；开启「自适应」后超出安全区的图形会自动缩放并居中，预览中的蓝框为行程范围、橙虚线为安全区。
    4. 
        
  4. 设置尺寸：关闭自适应时，填写目标宽度（毫米），高度会在锁定宽高比时自动计算。
    5. 
        
  5. 路径优化：默认使用「贪心 + 2-opt」重排走线，自动选择每段路径的最近端点并允许反向，配合衔接阈值把断点连成连续雕刻，可显著减少空移与激光开关次数。
    6. 
        
  6. 预览与导出：右侧画布可缩放 / 拖动查看，支持模拟雕刻动画；确认后下载 .gcode 或复制到其它软件。
    7. 
      

      
输出为 GRBL 兼容 G 代码（G0/G1 + M3/M4/M5 + S 功率）。不同机器的功率与速度差异较大，请先小尺寸试刻。
